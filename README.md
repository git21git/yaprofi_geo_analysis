## Аннотация

В работе представлен анализ географического распределения участников Всероссийской олимпиады студентов «Я – профессионал» по направлению «Компьютерные науки» за период IV–VIII сезонов (2020–2026 гг.). На основе официальных итоговых таблиц организационного комитета выполнена предобработка данных, расчёт производных показателей (доля медалистов, победителей, темп прироста). С применением языка R и пакетов `ggplot2`, `corrplot`, `wordcloud2`, `pheatmap`, `factoextra` проведён исследовательский анализ, корреляционно-регрессионный анализ, проверка статистических гипотез (t-тест, ANOVA) и кластеризация регионов методом k-means. Построены регрессионные модели, объясняющие результативность участия численностью студентов и количеством вузов. Результаты визуализированы в интерактивном HTML-отчёте с адаптивным дизайном, поддержкой светлой/тёмной темы и увеличением изображений. Полученные выводы могут быть использованы федеральными и региональными органами исполнительной власти для корректировки политики поддержки олимпиадного движения и талантливой молодёжи.

## Методология

### Источники данных
- Официальные итоговые таблицы олимпиады за IV–VIII сезоны (формат PDF, предоставлены организационным комитетом).
- Внешние статистические данные: численность студентов и количество вузов по субъектам РФ (Росстат, 2024 г.).

### Этапы обработки
1. Извлечение таблиц из PDF, унификация наименований регионов, конкатенация в единый датафрейм (322 наблюдения × 7 переменных).
2. Расчёт производных показателей: доля медалистов, доля победителей, цепные темпы прироста.
3. Исследовательский анализ: гистограммы, boxplot, тепловые карты, облако слов (wordcloud).
4. Корреляционный анализ (коэффициент Пирсона) и проверка гипотез (t-тест, ANOVA).
5. Построение множественной линейной регрессии и логарифмической модели.
6. Кластеризация методом k-means с предварительной стандартизацией признаков и выбором числа кластеров по методу локтя и силуэта.
7. Визуализация в R и создание HTML-отчёта.

### Инструментарий
- **Язык программирования:** R (версия 4.4)
- **Пакеты R:** `dplyr`, `tidyr`, `ggplot2`, `corrplot`, `wordcloud2`, `pheatmap`, `factoextra`, `lmtest`
- **Среда разработки:** RStudio
- **BI-платформа (для сравнения):** Glarus BI
- **Формирование отчёта:** HTML, CSS, JavaScript (адаптивная вёрстка, lightbox, тёмная тема)

## Ключевые результаты

1. **Регионы-лидеры** (суммарно за IV–VIII сезоны): Москва, Санкт-Петербург, Новосибирская область, Томская область, Свердловская область.
2. **Корреляционный анализ**:
   - Число дипломантов и численность студентов: \( r = 0,977 \) (p < 0,001).
   - Число дипломантов и количество вузов: \( r = 0,88 \) (p < 0,001).
3. **Регрессионная модель** (VIII сезон):
   \[
   \text{дипломанты} = -12,45 + 0,0134\cdot\text{students\_total} + 2,18\cdot\text{universities\_count}
   \]
   Коэффициент детерминации \( R^2 = 0,69 \), значимый предиктор – численность студентов.
4. **Проверка гипотез**:
   - t-тест не подтвердил значимого различия доли медалистов между лидерами и аутсайдерами.
   - ANOVA показала значимые различия среднего числа дипломантов между группами (p < 0,001).
5. **Кластеризация k-means (k=2)**:
   - Кластер 1: крупные образовательные центры с высокими показателями.
   - Кластер 2: остальные регионы.
6. **Динамика**:
   - Восходящий тренд: Нижегородская, Курская, Новосибирская области.
   - Нисходящий тренд: Томская, Самарская области, Республика Татарстан.
