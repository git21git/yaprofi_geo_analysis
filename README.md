<h1>Использование методов корреляционно-регрессионного анализа и алгоритма кластеризации k-means для определения основных изменений в географическом распределении участников всероссийской олимпиады «Я – профессионал» направления «Компьютерные науки»</h1>

<p><strong>Курсовая работа</strong><br>
<em>Чудинова Мария Александровна</em><br>
Дисциплина: «Языки программирования для статистической обработки данных»<br>
27 мая 2026 г.</p>

<hr>

<h2>Аннотация</h2>
<p>В работе представлен анализ географического распределения участников Всероссийской олимпиады студентов «Я – профессионал» по направлению «Компьютерные науки» за период IV–VIII сезонов (2020–2026 гг.). На основе официальных итоговых таблиц организационного комитета выполнена предобработка данных, расчёт производных показателей (доля медалистов, победителей, темп прироста). С применением языка R и пакетов <code>ggplot2</code>, <code>corrplot</code>, <code>wordcloud2</code>, <code>pheatmap</code>, <code>factoextra</code> проведён исследовательский анализ, корреляционно-регрессионный анализ, проверка статистических гипотез (t-тест, ANOVA) и кластеризация регионов методом k-means. Построены регрессионные модели, объясняющие результативность участия численностью студентов и количеством вузов. Результаты визуализированы в интерактивном HTML-отчёте с адаптивным дизайном, поддержкой светлой/тёмной темы и увеличением изображений. Полученные выводы могут быть использованы федеральными и региональными органами исполнительной власти для корректировки политики поддержки олимпиадного движения и талантливой молодёжи.</p>

<h2>Цели и задачи исследования</h2>
<p><strong>Цель</strong> – выявление основных изменений в географическом распределении участников олимпиады с использованием методов корреляционно-регрессионного анализа и алгоритма кластеризации k-means.</p>
<p><strong>Задачи:</strong></p>
<ol>
<li>Исследовать предметную область и структуру олимпиадных данных.</li>
<li>Выполнить предобработку и разведочный анализ (EDA).</li>
<li>Провести корреляционный анализ признаков.</li>
<li>Построить регрессионные модели для оценки влияния факторов на уровень участия.</li>
<li>Выполнить кластеризацию регионов методом k-means.</li>
<li>Визуализировать полученные результаты.</li>
<li>Сравнить возможности инструментов R и Glarus BI.</li>
</ol>

<h2>Объект и предмет исследования</h2>
<ul>
<li><strong>Объект</strong> – данные об участниках олимпиады «Я – Профессионал» по направлению «Компьютерные науки», агрегированные по регионам и сезонам.</li>
<li><strong>Предмет</strong> – статистические закономерности и изменения в географическом распределении участников, а также возможность группировки регионов по схожим характеристикам участия.</li>
</ul>

<h2>Методология</h2>
<h3>Источники данных</h3>
<ul>
<li>Официальные итоговые таблицы олимпиады за IV–VIII сезоны (формат PDF, предоставлены организационным комитетом).</li>
<li>Внешние статистические данные: численность студентов и количество вузов по субъектам РФ (Росстат, 2024 г.).</li>
</ul>

<h3>Этапы обработки</h3>
<ol>
<li>Извлечение таблиц из PDF, унификация наименований регионов, конкатенация в единый датафрейм (322 наблюдения × 7 переменных).</li>
<li>Расчёт производных показателей: доля медалистов, доля победителей, цепные темпы прироста.</li>
<li>Исследовательский анализ: гистограммы, boxplot, тепловые карты, облако слов (wordcloud).</li>
<li>Корреляционный анализ (коэффициент Пирсона) и проверка гипотез (t-тест, ANOVA).</li>
<li>Построение множественной линейной регрессии и логарифмической модели.</li>
<li>Кластеризация методом k-means с предварительной стандартизацией признаков и выбором числа кластеров по методу локтя и силуэта.</li>
<li>Визуализация в R и создание HTML-отчёта.</li>
</ol>

<h3>Инструментарий</h3>
<ul>
<li><strong>Язык программирования:</strong> R (версия 4.4)</li>
<li><strong>Пакеты R:</strong> <code>dplyr</code>, <code>tidyr</code>, <code>ggplot2</code>, <code>corrplot</code>, <code>wordcloud2</code>, <code>pheatmap</code>, <code>factoextra</code>, <code>lmtest</code></li>
<li><strong>Среда разработки:</strong> RStudio</li>
<li><strong>BI-платформа (для сравнения):</strong> Glarus BI</li>
<li><strong>Формирование отчёта:</strong> HTML, CSS, JavaScript (адаптивная вёрстка, lightbox, тёмная тема)</li>
</ul>

<h2>Ключевые результаты</h2>
<ol>
<li><strong>Регионы-лидеры</strong> (суммарно за IV–VIII сезоны): Москва, Санкт-Петербург, Новосибирская область, Томская область, Свердловская область.</li>
<li><strong>Корреляционный анализ</strong>:
<ul>
<li>Число дипломантов и численность студентов: \( r = 0,977 \) (p &lt; 0,001).</li>
<li>Число дипломантов и количество вузов: \( r = 0,88 \) (p &lt; 0,001).</li>
</ul>
</li>
<li><strong>Регрессионная модель</strong> (VIII сезон):
\[
\text{дипломанты} = -12,45 + 0,0134\cdot\text{students\_total} + 2,18\cdot\text{universities\_count}
\]
Коэффициент детерминации \( R^2 = 0,69 \), значимый предиктор – численность студентов.</li>
<li><strong>Проверка гипотез</strong>:
<ul>
<li>t-тест не подтвердил значимого различия доли медалистов между лидерами и аутсайдерами.</li>
<li>ANOVA показала значимые различия среднего числа дипломантов между группами (p &lt; 0,001).</li>
</ul>
</li>
<li><strong>Кластеризация k-means (k=2)</strong>:
<ul>
<li>Кластер 1: крупные образовательные центры с высокими показателями.</li>
<li>Кластер 2: остальные регионы.</li>
</ul>
</li>
<li><strong>Динамика</strong>:
<ul>
<li>Восходящий тренд: Нижегородская, Курская, Новосибирская области.</li>
<li>Нисходящий тренд: Томская, Самарская области, Республика Татарстан.</li>
</ul>
</li>
</ol>

<h2>Заключение</h2>
<p>В курсовой работе успешно применены методы корреляционно-регрессионного анализа и кластеризации k-means к данным олимпиады «Я – профессионал». Выявлены устойчивые регионы-лидеры, доказана определяющая роль численности студентов в формировании кадрового резерва IT-отрасли, предложена типология регионов по уровню участия. Результаты могут быть использованы органами управления образованием для адресной поддержки регионов с низкой вовлечённостью и для оценки эффективности стимулирующих мер.
