АННОТАЦИЯ

Курсовая работа посвящена анализу географического распределения участников Всероссийской олимпиады студентов «Я – профессионал» по направлению «Компьютерные науки» за период IV–VIII сезоны (2020–2026 гг.). В работе использованы методы корреляционно-регрессионного анализа, проверка статистических гипотез (t-тест, ANOVA) и алгоритм кластеризации k-means. Обработка данных выполнена в среде R с применением пакетов dplyr, ggplot2, corrplot, factoextra. Выявлены устойчивые тренды, регионы-лидеры и факторы, влияющие на результативность участия (численность студентов, количество вузов). Построены регрессионные модели с коэффициентом детерминации до 0,95. Разработаны рекомендации для организаторов олимпиады и региональных систем образования.

ГЛАВА 1. ТЕОРЕТИЧЕСКИЕ ОСНОВЫ СТАТИСТИЧЕСКОЙ ОБРАБОТКИ ДАННЫХ

В первой главе рассмотрены предметная область олимпиады «Я – профессионал», основные методы статистического анализа (корреляция, регрессия, кластеризация), а также возможности языка R и BI-платформы Glarus. Обоснован выбор R для реализации исследовательского анализа и k-means, а Glarus – для интерактивных дашбордов.

Краткое содержание: описаны источники данных, структура панельных данных (322 наблюдения, 7 переменных), этапы предобработки (извлечение из PDF, унификация регионов, расчёт производных показателей).

ГЛАВА 2. ПРАКТИЧЕСКАЯ РЕАЛИЗАЦИЯ ИССЛЕДОВАНИЯ

2.1. Описание используемых данных

Эмпирическую базу составили официальные итоговые таблицы олимпиады за IV–VIII сезоны (формат PDF). После ручной выверки и конкатенации получен датасет, содержащий сведения о количестве медалистов, победителей, призёров и общем числе дипломантов по регионам РФ. Внешние данные о численности студентов и количестве вузов добавлены из статистических сборников Росстат (2024 г.). Производные показатели: доля медалистов, доля победителей, темп прироста дипломантов.

Построены линейные графики динамики для ведущих регионов, тепловая карта по федеральным округам, облако слов (wordcloud) для суммы медалистов.

2.3.1. Описательная статистика

2.3.2. Проверка гипотез

Гипотеза 1 (t-test): доля медалистов в регионах-лидерах не отличается значимо от аутсайдеров (p-value = 0,437). Гипотеза 2 (ANOVA): среднее число дипломантов между группами различается (p < 2.2e-16). Post-hoc попарные сравнения показали значимые различия между лидерами и двумя другими группами, но не между срединными и аутсайдерами.

2.3.3. Регрессионный анализ

Построена множественная линейная регрессия для VIII сезона: зависимая переменная — число дипломантов, предикторы — численность студентов (тыс. чел.) и количество вузов. Модель:

\[ \text{дипломанты}_i = -12.45 + 0.0134 \cdot \text{students\_total}_i + 2.18 \cdot \text{universities\_count}_i + \varepsilon_i \]

Коэффициент при численности студентов значим (p < 0.001), при количестве вузов — нет (p = 0.26). \(R^2 = 0.69\), скорректированный \(R^2 = 0.68\). Логарифмическая модель показала эластичность 0.74 для численности студентов. Основной вывод: масштаб студенческого контингента — ключевой фактор успеха региона в олимпиаде.

2.4. Машинное обучение: кластеризация регионов методом k‑means

Признаки: суммарное число дипломантов, средняя доля медалистов, число вузов, темп прироста. Данные стандартизированы. Методом локтя и силуэта выбрано оптимальное число кластеров k=2. Результат разделил регионы на две группы: «Кластер 1» — крупные образовательные центры с высокими показателями (Новосибирская, Свердловская, Томская области и др.), «Кластер 2» — все остальные регионы с более низкими значениями. Интерпретация подтверждает поляризацию образовательного пространства РФ.

ЗАКЛЮЧЕНИЕ

В ходе курсовой работы выполнено комплексное статистическое исследование географического распределения дипломантов олимпиады «Я – профессионал». Основные результаты:

  • Выявлены устойчивые регионы-лидеры: Москва, Санкт-Петербург, Новосибирская, Свердловская, Томская области.
  • Установлена сильная корреляция между численностью студентов и количеством дипломантов (\(r=0.977\)).
  • Построена регрессионная модель, объясняющая 69% дисперсии результативности.
  • Кластеризация k-means подтвердила разделение регионов на два основных кластера по уровню активности.
  • Разработаны рекомендации по усилению подготовки в «срединных» регионах для сглаживания поляризации.

Практическая значимость работы заключается в создании методики мониторинга региональной результативности, которая может быть использована организаторами олимпиады и органами управления образованием.
